The 2026-09-26 review findings have been addressed in the game and a focused
Labrador path-loading fix. The game's OOP model and default backends are
unchanged.

- Flying paint resolves its first swept impact before the scene's discrete
  contacts. The impact footprint accounts for travel and diffusion, so thin
  paint strips are hit and backing geometry cannot consume a shot first.
  Launches away from an adjacent wall remain clear; launches through cover
  remain blocked. Rollers retain multiple contacts and their one-step life.
- Stage confirmation/cancellation takes one shared step per update. Team and
  weapon cancellation use the frame's initial readiness state, preserving
  simultaneous independent player input without backing out two steps.
- Content and save paths preserve Unicode. The Labrador change is based on
  the prior pin and does not include unrelated later engine work. ColourWars
  uses the same UTF-8 path convention for save reads, replacement writes,
  migration and fallback; native Windows file operations use wide paths.
- Startup resolves all tuned/presentation resource references and fixed menu
  frames, including animations previously resolved only during play. Errors
  name the file and authored key. Optional silent banks retain their existing
  permissive sound-name behavior.
- HUD reference widths and results fill duration must be finite and positive.
  Invalid values now fail when presentation data is read.
- A generated wave bank is explicitly staged after its recipe, including its
  first build. The Release ZIP still excludes all audio.
- The audio-report ledger now records the existing per-emitter mixing exhibit
  and the report's unfiled status.
